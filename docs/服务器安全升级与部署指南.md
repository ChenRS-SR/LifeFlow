# LifeFlow 2.0 安全升级与 admin 账户迁移部署指南

> 适用场景：本次 commit `26cd270` 起的安全修复部署到公网服务器（Alibaba Cloud）。
> 目标：移除默认 admin/admin123 后门、关闭认证绕过、配置强 SECRET_KEY，并把已有 admin 改名为 `chenrs12138`、保留全部数据。

---

## 一、本次代码变更要点

1. **移除 `token_1` / `token_2` 简单认证绕过**（`backend/app/api/deps.py`）
2. **前端不再发送假 token**（`frontend/src/services/api.ts`）
3. **生产环境必须设置 `SECRET_KEY`**，否则服务拒绝启动（`backend/app/core/config.py`）
4. **生产环境不再自动创建 `admin/admin123`**；开发环境仍自动创建 admin，但密码随机（`backend/app/main.py`）
5. **新增 `ALLOW_REGISTRATION` 注册开关**，公网建议关闭（`backend/app/core/config.py`、`backend/app/api/auth.py`）
6. **新增账户迁移脚本** `backend/scripts/migrate_rename_admin.py`，可在容器内执行
7. **Docker 镜像已包含 scripts 目录**，compose 默认 `ENVIRONMENT=production`、`ALLOW_REGISTRATION=false`
8. **登录页已移除硬编码 admin/admin123 一键登录入口**，改为普通用户名/密码表单

## 二、服务器部署步骤

### 1. SSH 登录并进入项目

```bash
cd /opt/LifeFlow
```

### 2. 拉取最新代码

```bash
git pull origin dev-2.0
```

### 3. 备份数据库（关键！）

```bash
cp docker/data/lifeflow.db docker/data/lifeflow.db.bak.$(date +%Y%m%d_%H%M%S)
```

### 4. 配置环境变量

```bash
cp docker/.env.example docker/.env
vim docker/.env
```

必须填写以下三项：

```bash
ENVIRONMENT=production
SECRET_KEY=<强随机字符串，至少 32 字节>
ALLOW_REGISTRATION=false
```

生成 `SECRET_KEY` 示例：

```bash
openssl rand -base64 32
```

`ALLOW_REGISTRATION=false` 表示关闭开放注册，仅你手动创建的账户可登录。

### 5. 构建并启动服务

```bash
docker compose down
docker compose up -d --build
```

如果 `.env` 没填 `SECRET_KEY`，容器会因 `ValueError` 启动失败，日志里会有明确提示。

### 6. 运行 admin 改名脚本

新镜像已经把 `backend/scripts/` 复制到 `/app/scripts/`。在容器内执行：

```bash
docker compose exec backend python scripts/migrate_rename_admin.py --db /app/data/lifeflow.db
```

按提示输入 `chenrs12138` 的新密码两次。脚本会：

- 查找 `username = 'admin'` 的记录；
- 把用户名改为 `chenrs12138`；
- 用 bcrypt 重新生成 `hashed_password`；
- `user_id` 不变，所有 habits / tasks / projects / goals / reviews 等数据自动保留。

### 7. 验证

```bash
# 查看后端日志
docker compose logs -f backend

# 确认没有 admin 用户（在宿主机上直接查 DB）
sqlite3 data/lifeflow.db "SELECT id, username FROM users;"
```

应只看到 `chenrs12138`，不再有 `admin`。

然后打开浏览器，用 `chenrs12138` + 新密码登录，检查数据是否都在。注意：登录页已移除“一键登录默认账户”按钮，改为普通用户名/密码表单。如果浏览器还显示旧页面，请强制刷新（Ctrl + F5 或清除缓存）。

## 三、回滚方式

如果升级或迁移后异常，按以下步骤回滚：

```bash
cd /opt/LifeFlow
docker compose down

# 恢复数据库备份
cp docker/data/lifeflow.db.bak.XXXXXX docker/data/lifeflow.db

# 如果要回到旧代码，先 checkout 到上一个 commit
git log --oneline -5
git checkout <上一个 commit>

# 重新启动旧版本
docker compose up -d --build
```

## 四、常见问题

**Q：迁移脚本提示 `No module named 'passlib'` 怎么办？**  
A：请确保你是在 `backend` 容器内执行：`docker compose exec backend python scripts/migrate_rename_admin.py --db /app/data/lifeflow.db`。容器镜像已安装 `passlib`。

**Q：登录后提示 401 / token 无效？**  
A：
1. 确认 `SECRET_KEY` 已设置且容器重启后未变；
2. 清除浏览器 `localStorage` 中的 `token` 和 `user`，重新登录；
3. 本次代码已移除前端 `token_1` 兜底，未登录或 token 过期会正确跳转登录页。

**Q：想临时允许朋友注册怎么办？**  
A：修改 `docker/.env` 中 `ALLOW_REGISTRATION=true`，然后 `docker compose up -d` 重启 backend 容器即可。注册完建议再改回 `false`。
